# 视频编辑工具使用指南

## 功能概述

视频编辑工具提供了完整的前端视频处理功能，包括：

- 🎬 **视频剪切** - 精确剪切视频片段
- 🔗 **视频合并** - 将多个视频合并为一个
- 🔄 **视频转换** - 格式转换、分辨率调整
- 📸 **帧提取** - 提取视频关键帧
- 🎵 **音频提取** - 从视频中提取音频

## 访问方式

1. 启动开发服务器：`npm run dev`
2. 在左侧导航栏中找到"视频编辑"菜单项
3. 点击进入视频编辑工具页面

## 功能详解

### 1. 视频剪切

**功能**：从视频中剪切指定时间段的片段

**使用步骤**：
1. 选择视频文件
2. 设置开始时间和结束时间
3. 选择输出格式（MP4、WebM、AVI）
4. 选择编码模式：
   - 快速模式：保持原始编码，速度快
   - 精确模式：重新编码，质量可控
5. 点击"开始剪切"

**注意事项**：
- 支持的输入格式：MP4、WebM、AVI、MOV等
- 精确模式处理时间较长但质量更好
- 建议视频分辨率为偶数避免编码错误

### 2. 视频合并

**功能**：将多个视频文件合并成一个

**使用步骤**：
1. 上传多个视频文件（至少2个）
2. 拖拽调整视频顺序
3. 配置合并设置：
   - 输出格式
   - 视频编码（H.264、H.265、VP9）
   - 视频质量
   - 音频质量
   - 输出分辨率
4. 可选启用交叉淡入效果
5. 点击"开始合并"

**高级功能**：
- 支持不同格式视频的合并
- 自动统一分辨率和帧率
- 交叉淡入淡出效果

### 3. 视频转换

**功能**：转换视频格式、调整分辨率和帧率

**使用步骤**：
1. 选择视频文件
2. 设置输出参数：
   - 输出格式
   - 分辨率
   - 帧率
   - 视频质量
3. 点击"开始转换"

### 4. 帧提取

**功能**：从视频中提取静态图片帧

**使用步骤**：
1. 选择视频文件
2. 设置提取参数：
   - 帧数量
   - 输出尺寸
   - 图片格式（PNG、JPG、WebP）
   - 提取模式：
     - 均匀分布：等间隔提取
     - 关键帧：提取关键帧
     - 场景变化：检测场景变化点
3. 点击"提取帧"
4. 可预览和下载单个帧或批量下载

### 5. 音频提取

**功能**：从视频中提取音频轨道

**使用步骤**：
1. 选择视频文件
2. 设置音频参数：
   - 输出格式（MP3、WAV、AAC、OGG）
   - 音频质量
   - 采样率
   - 声道数
   - 时间范围（可选）
3. 点击"提取音频"

## 环境诊断

如果遇到"SharedArrayBuffer不可用"错误，请：

1. 点击页面右上角的"环境诊断"按钮
2. 查看诊断结果和建议
3. 确保：
   - 使用HTTPS或localhost环境
   - 浏览器支持（Chrome 68+, Firefox 79+, Safari 15.2+）
   - 正确配置了CORS头部

## 技术特点

- ✅ **纯前端处理** - 无需服务器，数据不上传
- ✅ **高性能** - 基于FFmpeg.wasm，接近原生性能
- ✅ **多格式支持** - 支持主流视频/音频格式
- ✅ **实时预览** - 处理前后对比预览
- ✅ **批量操作** - 支持多文件批量处理

## 性能建议

1. **文件大小**：建议单个文件不超过500MB
2. **浏览器内存**：处理大文件时确保足够的内存
3. **网络环境**：首次加载需要下载FFmpeg核心文件
4. **硬件加速**：现代浏览器会自动使用硬件加速

## 常见问题

**Q: 处理速度很慢？**
A: 大文件处理需要时间，建议使用快速模式或降低质量设置

**Q: 某些格式不支持？**
A: 确保浏览器支持该格式，或先转换为MP4格式

**Q: 内存不足错误？**
A: 关闭其他标签页释放内存，或处理较小的文件

**Q: SharedArrayBuffer错误？**
A: 使用环境诊断工具检查，确保正确的CORS配置
